# 🛠️ 爸气实用工具箱 (Daddy's Practical Toolbox)

> **90后金融奶爸的硬核育儿 & 职场生存指南**
> *"左手换尿布，右手敲代码；上班专注摸鱼，下班科学带娃。"*

## 📖 项目简介 (Introduction)

**爸气实用工具箱** 是一款专为新一代年轻父亲（特别是像我这样的金融/互联网从业者）打造的**全栈式辅助工具**。

它不仅仅是一个记录宝宝成长的工具，更是一个将“家庭项目管理”与“职场情绪价值”完美融合的超级App。我们用**做IPO尽调**的严谨态度备孕，用**项目运营**的思维带娃，同时还内置了职场解压神器，帮助奶爸们在“好爸爸”和“打工人”的双重身份中寻找平衡。

## 🌟 核心功能 (Features)

本项目包含五大核心模块，构建了从家庭到职场的完整闭环：

### 1. 🏁 爸气攻略 (Parenting Roadmap)

**"用投行思维做育儿项目管理"**

* **备孕尽调 (Pre-pregnancy)**: 像做风控一样管理备孕指标，计算 ROI。
* **孕期建设 (Pregnancy)**: 40周全景地图，关键节点提醒，里程碑管理。
* **育儿运营 (Parenting)**: 实战技能树解锁，从“新手村”到“资深合伙人”。
* **特色**: 支持生成周报/日报分享，向家庭股东（老婆/长辈）汇报工作。

### 2. 📝 成长记录 (Growth Record)

**"多宝模式的数据中台"**

* **多宝支持**: 完美支持大宝、二宝甚至三宝的数据独立管理。
* **极速记录**: 喂奶（亲喂/瓶喂）、换尿布（粑粑/嘘嘘）、吸奶量，一键打点。
* **可视化**: 自动生成今日数据简报，拒绝糊涂账。

### 3. 🌊 声波空间 (Sound Space)

**"宝宝的安抚奶嘴，爸爸的录音棚"**

* **白噪音矩阵**: 内置子宫心跳、雨声、海浪等高品质白噪音，一键哄睡。
* **亲子录音**: 爸爸亲自录制睡前故事，建立深层亲子链接。

### 4. 💰 省钱福利 (Welfare & Deals)

**"金融奶爸的开源节流术"**

* **午餐大转盘**: 解决“中午吃什么”的世纪难题。
* **全网比价**: 集成外卖红包、特惠出行、限时囤货（尿不湿/奶粉）信息。
* **羊毛雷达**: 实时更新优惠信息，精打细算过日子。

### 5. 🐟 FlowState (摸鱼/专注模式)

**"隐藏在首页的职场解压神器"**

* **Zen Mode (禅意模式)**: 极简时钟 + 喝水打卡，帮助你进入心流状态。
* **Mad Mode (发疯模式)**: 摇一摇进入！复古 Windows 风格，**实时计算薪资**（看着工资按秒上涨，瞬间解压）。
* **游戏化体验**: 内置“带薪拉屎”、“摸鱼商店”、“成就系统”（如：资本家克星）。

## 🛠️ 技术栈 (Tech Stack)

* **平台**: 微信小程序原生开发 (Native WeChat Mini Program)
* **语言**: JavaScript (ES6+), WXML, WXSS
* **数据存储**: `wx.setStorageSync` (本地离线存储，保护隐私)
* **硬件调用**: 加速度计 (摇一摇)、录音管理器、音频播放器、震动反馈
