## 📖 项目简介 (Introduction)

**爸气实用工具箱** 是一款专为新一代年轻父亲（特别是像我这样的金融/互联网从业者）打造的**全栈式辅助工具**。

它不仅仅是一个记录宝宝成长的工具，更是一个将**“家庭项目管理”**与**“职场情绪价值”**完美融合的超级App。我们用**做IPO尽调**的严谨态度备孕，用**项目运营**的思维带娃，用**风控审计**的标准选零食，同时还内置了职场解压神器，帮助奶爸们在“好爸爸”和“打工人”的双重身份中寻找平衡。

## 🌟 核心功能 (Features)

本项目包含六大核心模块，构建了从家庭风控到职场生存的完整闭环：

### 1. 📡 狠活雷达 (Hex Radar) `[v3.0 NEW!]`

**"家庭供应链尽职调查终端 (Supply Chain Due Diligence)"**

* **AI 穿透审计**: 基于 **OCR 文字识别技术**，一键拍摄零食配料表，让“科技与狠活”无所遁形。
* **金融级风控模型**:
* 建立 **GB2760** 本地法规库，识别防腐剂、代可可脂、反式脂肪等 50+ 种风险成分。
* 将成分转化为资产评级：**AAA级** (核心优质资产) 到 **D级** (垃圾债/有毒资产)。


* **位置权重算法 (Positional Weight)**:
* **🚨 主料暴击**: 坏成分排在前 30%？权重 1.5 倍扣分（高亮红标）。
* **🤏 微量豁免**: 坏成分排在后 30%？权重 0.8 倍宽容（灰色标记）。


* **首席风控官点评**: 根据综合评分，输出犀利的“爸气”投资建议（如：“建议立即并购”或“直接熔断”）。

### 2. 💰 现金流优化 (Cash Flow & Arbitrage)

**"金融奶爸的开源节流术"**

* **全渠道套利矩阵**: 集成美团、饿了么、淘宝闪购、京东外卖四大渠道。
* **资产注入**: 支持 **“全能口令”** 复制，自动唤起电商 App 识别，实现优惠券精准打击。
* **爸气出游**: 严选携程酒店特卖（🏨），锁定高性价比差旅/亲子游标的。
* **午餐大转盘**: 引入随机游走算法，解决“中午吃什么”的决策瘫痪问题。

### 3. 🏁 爸气攻略 (Parenting Roadmap)

**"用投行思维做育儿项目管理"**

* **备孕尽调**: 像做风控一样管理备孕指标，计算 ROI。
* **孕期建设**: 40周全景地图，关键节点提醒，里程碑管理。
* **育儿运营**: 实战技能树解锁，从“新手村”到“资深合伙人”。

### 4. 📝 成长记录 (Growth Record)

**"多宝模式的数据中台"**

* **多宝支持**: 完美支持大宝、二宝甚至三宝的数据独立管理。
* **极速打点**: 喂奶、换尿布、吸奶量一键记录，可视化生成今日数据简报，拒绝糊涂账。

### 5. 🌊 声波空间 (Sound Space)

**"宝宝的安抚奶嘴，爸爸的录音棚"**

* **白噪音矩阵**: 内置子宫心跳、雨声、海浪等高品质白噪音。
* **亲子录音**: 爸爸亲自录制睡前故事，建立深层亲子链接。

### 6. 🐟 FlowState (摸鱼/专注模式)

**"隐藏在首页的职场解压神器"**

* **Mad Mode (发疯模式)**: 摇一摇进入！复古 Windows 风格，**实时计算薪资**（看着工资按秒上涨，瞬间解压）。
* **游戏化体验**: 内置“带薪拉屎”、“摸鱼商店”、“成就系统”（如：资本家克星）。
