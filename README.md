## 3. 👨‍💻 运维操作指南 (Ops Manual)

**这是您上线后最需要关注的部分：**

### A. 如何更新“避雷社区”内容？

1. **收集**：在“客服小助手”接收用户投稿图片。
2. **编辑**：打开 `data/community_data.js`。
3. **录入**：在数组头部添加新对象：
```javascript
{ 
  id: Date.now(), // 唯一ID
  title: '避雷标题', 
  img: '图片链接(可用图床或公众号封面)', 
  risk: '检出成分', 
  level: 'D', 
  user: '投稿人昵称', 
  time: '发布时间',
  is_sticky: false, // 是否置顶
  articleUrl: '公众号文章链接(可选)' 
}

```


4. **发版**：提交审核 -> 发布。

### B. 如何调整“风控算法”？

* **位置**：`utils/risk_db.js`
* **操作**：添加新的科技狠活关键词或调整风险等级。
* **注意**：算法逻辑在 `scanner.js` 中，已包含“前置否定/后置含量”的防误判逻辑，通常无需修改代码，只需维护数据库。

### C. 如何更换“恰饭”链接？

* **位置**：`pages/index/index.js`
* **操作**：搜索 `goToMeituan` 等函数，替换 `path` (小程序) 或 `url` (H5) 为最新的 CPS 推广链接。
